# TXT/EPUB 剧本识别工作区

文档状态：Recognition schema v1  
适用阶段：第 34 轮

## 1. 目标与边界

识别工作区把 TXT/EPUB 资料转换为可复核的结构候选，而不是直接生成并安装正式世界。当前流程固定为：

```text
本地来源 → SHA-256 身份绑定 → TXT/EPUB 解析
→ 角色/地点/场景/目标/候选事实
→ 来源范围与置信诊断 → 只读复核工作区
```

识别结果只属于草稿命名空间。第 35 轮的聚合可玩性验证、隔离试玩与原子安装完成前，工作区始终禁用“试玩”和“安装”。识别过程不能修改内置世界目录、正式 Run、EventLog 或玩家存档。

## 2. 可恢复任务

`RecognitionJobState` 使用 schema v1，保存稳定 JobId、来源文件名/格式、来源 SHA-256、修订号、阶段、状态、进度检查点、诊断和已发布草稿版本。SQLDelight `content_recognition_job` 表通过 revision 比较拒绝陈旧写入。

恢复必须重新提供来源字节并核对 SHA-256、文件名和格式：

- 相同来源从最后可用阶段继续，已经发布的草稿不会再次调用识别模型；
- 来源变化会把旧任务标记为 `SOURCE_CHANGED`，必须使用新 JobId 创建显式新版本；
- 用户取消或协程取消会清除解析正文与未发布草稿，只保留来源身份、阶段和安全诊断；
- 解析/识别在工作 Dispatcher 上运行，协程取消会继续向上传播。

## 3. 来源映射

每个候选项必须包含：

- 稳定候选 ID 和 `CHARACTER`、`LOCATION`、`SCENE`、`OBJECTIVE` 或 `CANDIDATE_FACT` 类型；
- `SourceChunk` 片段 ID；
- 位于该片段 Locator 内的起止字符范围；
- `HIGH`、`MEDIUM` 或 `LOW` 置信级别及非空判断说明。

缺少片段、范围越界或缺少置信说明会形成可定位错误，不会用默认来源掩盖。工作区按候选展示来源标签，只有作者选择候选后才展示最多 320 字的局部上下文，不展示整篇资料。

## 4. 隐私与日志

任务诊断只保存固定错误类别和长度受限的安全说明，不保存完整来源、Provider 原始错误、密钥或模型私有上下文。来源正文可以在活动任务的本地数据库记录中作为恢复检查点存在，但取消时会被清除；它不会写入 EventLog、公开回放或普通应用日志。

## 5. 验收范围

自动化测试覆盖 SHA-256 已知向量、TXT/EPUB 既有编码与大小边界、检查点取消/恢复、SQL 重建、来源变化、重复恢复不重新发布、协程取消、来源范围、置信诊断、局部上下文和未验证草稿门禁。三端只编译共享识别和 UI；iOS 压缩 EPUB/GB18030 平台桥仍是现有已知限制。
