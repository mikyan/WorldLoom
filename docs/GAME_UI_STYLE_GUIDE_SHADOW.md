# Worldloom 游戏页面风格审阅记录（Shadow）

状态：Non-normative<br>
记录日期：2026-09-01

本文件仅保存制定游戏页面风格规范时观察到的历史情况，不定义目标设计、不作为实现或验收依据，也不被项目设计文档引用。后续页面变化不要求同步更新本文件。

## 审阅快照

对当时的共享源码与 Desktop 实际画面盘点如下：

| 区域 | 当时已有表现 | 当时观察到的差异 |
|---|---|---|
| 首页与梦境选择 | 全屏场景图、金色描边、暗紫梦茧与叙事文案已经形成明确品牌感 | 颜色、圆角、按钮和遮罩定义在页面内部，其他页面无法复用 |
| 角色创建 | 动态 Profile 和字段编辑已经可用 | 全宽开发表单直接显示 DefinitionId、`IntegerValue(...)` 等内部表达，缺少背景、步骤、摘要与层级 |
| 主游戏页 | 背景图、玻璃面板、PM/NPC 色彩和桌面双栏已接近目标方向 | 局部 token 再次独立定义；小字、按钮层级、HUD 密度和边框语义不稳定 |
| 存档与设置 | 功能完整，使用共享 Material 组件 | 外层具有梦境风格，内层更接近通用后台面板；主次按钮、状态反馈和表单宽度没有统一规则 |
| 识别工作区 | 有进度、诊断、候选和操作区 | 组件主要使用默认 Card/Button，与玩家侧体验缺少共同骨架 |

当时的归纳是：不一致不只来自颜色差异，还来自品牌层、页面密度、组件语义和响应式规则分别在页面内部发展。该判断用于帮助形成后续规范，不代表当前实现状态。
