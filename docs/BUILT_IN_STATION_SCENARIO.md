# 《静默轨道：赫利俄斯危机》内置短剧本

文档状态：Content v2  
预计时长：约 60 分钟

## 1. 试玩目标

这是 Worldloom 的第二个完整内置世界。玩家扮演赫利俄斯空间站的核心 AI，在能源网格、冷却系统、乘员安全和自身完整性之间作出选择。它与战争世界共用同一套建角、主持、NPC、规则模块、存档和回放管线，不要求 Runtime 识别 `station.*` 字段或空间站题材。

```text
选择空间站世界 → 点数建角 → 主持人呈现系统危机
→ 自然语言或快捷行动 → 确定性检定与模块裁决
→ 莱拉/索伦定向对话与知识揭示 → 三类结局 → 存档/回放
```

内容固定为 `contentVersion = 2`、`catalogPriority = 90`。旧的内容 v1 Run 不会被静默当作 v2 恢复。

## 2. 内容结构

- 9 个场景：核心控制层、维护脊柱、居住环、冷却井、外环中继、档案舱、隔离沙箱、指挥环与救生艇；
- 17 个关键行动、8 个公开目标和成功、代价成功、失败 3 个可达结局；
- 世界时间、活动、旅行、库存、状态、关系、任务、进度钟及 3 个可恢复 Behavior；
- 首次教程和按场景提示只生成建议输入，不替玩家提交事实；
- 值班员莱拉与工程师索伦拥有独立身份、目标、知识、Session、记忆和公开动作白名单。

失败不是默认死路。系统检定失败会进入隔离沙箱；重启失败仍可推进到救生艇，最后能源可以换取撤离窗口或明确失败结局。资源与选择造成的代价通过事件和结局投影保留，而不是由叙述临时决定。

## 3. 主持人与 NPC 边界

主持人只获得当前玩家可见 Presentation、场景描述、参与者、动态行动、已揭示知识和公开事件证据。模型提出的行动必须经过 Tool Gateway、类型化 Command、Validator、WorldEngine、EventLog 与 Reducer；公开叙事不替代裁决。

莱拉知道一次未写入公开日志的中继认证失败；索伦知道维护隔离器被手动锁死。两段私有正文只进入对应 NPC 的上下文。角色主动揭示时，Runtime 只接受其白名单知识 ID，并把世界包固定的公开摘要写入 `NpcKnowledgeRevealedEvent`。玩家在场景中定向发言只唤醒选中的 NPC，场景外角色和其他 NPC 的知识均被拒绝。

## 4. 黄金路线

| 路线 | 主要推进 | 结局 |
|---|---|---|
| 黎明重启 | 重定向能源 → 修复冷却 → 协调乘员 → 恢复中继 → 核对档案 → 恢复控制 | 成功：黎明重启 |
| 带伤守望 | 人员优先 → 牺牲阵列排热 → 带代价恢复中继 → 安全模式 | 代价成功：带伤守望 |
| 静默阴影 | 核心锁死 → 只读重启失败 → 最后维持失败 | 失败：静默坠入阴影 |

三条路线都通过应用层的类型化主持命令从建角运行到结局，写入 SQLDelight EventLog 和 Snapshot，再执行公开回放与进程重建恢复。NPC 合同测试另外覆盖莱拉、索伦的动态对话目标、固定知识摘要和公开回放隐私。
