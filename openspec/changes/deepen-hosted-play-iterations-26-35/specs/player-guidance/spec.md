## ADDED Requirements

### Requirement: 世界包必须能够声明通用教程与场景提示
系统 SHALL 加载版本化教程步骤、触发条件、提示文本和目标行动 ID，并 MUST 校验所有引用与可见性；Runtime 不得按 worldId 或题材分支。

#### Scenario: 首次进入场景显示提示
- **WHEN** 玩家第一次满足教程步骤触发条件
- **THEN** UI 显示对应提示和可访问的行动入口，完成后不重复强制遮挡

#### Scenario: 悬空提示引用
- **WHEN** 世界包提示引用不存在或当前模块未启用的行动
- **THEN** 世界包在加载/安装前返回带路径的验证错误

### Requirement: 活跃 Run 不得出现无反馈死路
如果 Run 尚未结束但没有可用行动、活动或旅行，应用层 MUST 返回题材无关的恢复诊断和至少一个已验证推进建议，或明确将世界包判为不可玩。

#### Scenario: 动态卡关检测
- **WHEN** 当前场景所有入口都因状态条件关闭且没有失败出口
- **THEN** 系统显示内容诊断而不是让输入区无响应，黄金路线模拟将该世界判为失败

### Requirement: 引导必须尊重可访问性与玩家控制
教程 SHALL 支持跳过、重新查看和减少动态效果；快捷建议 SHALL 作为可选输入而非替玩家自动提交事实。

#### Scenario: 跳过教程
- **WHEN** 玩家选择跳过教程
- **THEN** UI 保留正常自然语言输入和场景行动，且不向 EventLog 写入任何世界事实变化
